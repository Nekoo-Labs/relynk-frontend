# Relynk

### **Name:** Relynk

**Tagline:** _"Create. Share. Get Paid. All Onchain."_

### 🎯 **Overview:**

**Relynk** is a Web3-native monetization tool that lets creators, freelancers, and digital hustlers **create payment links**, **sell digital products**, and **unlock content access** — all without relying on Web2 platforms or centralized gatekeepers.

It brings the simplicity of [lynk.id](http://lynk.id), **Mayar.id / Gumroad**, but powered by **crypto, smart contracts, and self-custody.**

---

### 🔑 **Core MVP Features:**

| Feature                      | Description                                                                                                                                  |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **🔗 Onchain Payment Links** | Instantly generate a smart contract-backed link to receive crypto payments (USDC, IDRX, etc.). Fixed price, dynamic price or donation-based. |
| **📁 Sell Digital Products** | Upload files (e.g. eBooks, templates) to IPFS and deliver them automatically after payment confirmation.                                     |
| **🎟️ Token-Gated Access**    | Give access to links/files/pages once payment is completed. Use SBT/NFT as proof.                                                            |
| **🧾 Mini Checkout Page**    | Custom checkout page per product. Shows price, wallet connect, and pay button.                                                               |
| **🪪 Wallet + Social Login**  | User-friendly onboarding using Privy (Gmail, Telegram) + EVM wallet support.                                                                 |

---

### 🛠️ **User Flow MVP:**

1. **Login** → via wallet or Telegram/Gmail (Privy)
2. **Create Product** → Upload file, set price, set price + description, customize link
3. **Share Link** → on Twitter, bio, Telegram, etc.
4. **Buyer Pays** → via wallet (only stablecoin) → gets tokenized access/transaction triggers access
5. **Content Delivered/Access Granted** → buyer can download content or unlock access page

---

### 📦 Use Cases:
